    O sistema operacional é o software principal que atua como intermediário entre você, os programas e o hardware do computador. Sem ele, o processamento e a interação com a máquina seriam muito mais difíceis.

    Ele organiza tarefas, controla recursos e garante que cada programa receba o que precisa para funcionar corretamente. Windows, macOS, Android e Linux são exemplos de sistemas operacionais.

    Principais funções

    • Gerenciamento de processos: decide quando um programa executa.
    • Gerenciamento de memória: reserva e distribui memória.
    • Gerenciamento de arquivos: organiza dados em pastas e arquivos.
    • Gerenciamento de dispositivos: controla teclado, mouse, disco e rede.
    • Gerenciamento de usuários: define quem pode acessar o quê.

    2. Conhecendo o Linux

    O que é Linux?

    Um pouco de história

    Em 1991, o estudante finlandês Linus Torvalds começou a escrever, como um projeto pessoal, um kernel (núcleo) de sistema operacional. Ele publicou o código na internet e pessoas do mundo todo passaram a contribuir.

    Desde 1983, o Projeto GNU, iniciado por Richard Stallman, desenvolvia ferramentas livres (compilador, shell, utilitários). O kernel Linux somado às ferramentas GNU formou um sistema completo; por isso muita gente diz GNU/Linux.

    Software livre e código aberto

    O Linux é distribuído sob a licença GPL. Isso garante quatro liberdades a qualquer pessoa:

    • Usar o programa para qualquer finalidade.
    • Estudar como ele funciona, lendo o código-fonte.
    • Modificar e adaptar às suas necessidades.
    • Distribuir cópias, originais ou modificadas.

    Estrutura do Linux

    Kernel

    É o núcleo do sistema. Ele gerencia memória, processos, arquivos e dispositivos.

    Distribuição

    É a combinação do kernel com ferramentas, programas e pacotes do sistema.

    Interface gráfica

    É a camada visual para interagir com o sistema, como janelas e ícones.

    Shell

    É o interpretador de comandos (como o bash), onde você digita ordens para o sistema.

    Distribuições populares

    Ubuntu

    Focado em facilidade de uso e com ampla adoção em desktops e servidores.

    Debian

    Conhecida pela estabilidade e confiabilidade; é a base do Ubuntu e de muitas outras.

    Fedora

    Traz tecnologias novas rapidamente e é usada em ambientes de inovação e desenvolvimento.

    Linux Mint

    Baseada no Ubuntu, tem visual familiar para quem está vindo do Windows.

    Arch Linux

    Minimalista: você monta o sistema peça por peça. Ótima para aprender a fundo.

    Onde o Linux aparece?

    • Computadores pessoais e notebooks.
    • Servidores web e bancos de dados: a maior parte da internet roda em Linux.
    • Celulares Android, que usam o kernel Linux.
    • Dispositivos embarcados, roteadores e smart TVs.
    • Ambientes de desenvolvimento, nuvem e supercomputadores.

    3. Organizando arquivos

    Arquivos e diretórios

    No Linux tudo parte de um único ponto, a raiz (/). Não existe “C:” ou “D:”: discos e pendrives aparecem como pastas dentro dessa árvore. 

    /
├── bin/
├── boot/
├── dev/
├── etc/
├── home/
│   └── aluno/
├── root/
├── tmp/
├── usr/
└── var/

    /bin

    Programas essenciais do sistema, como ls, cp e bash. No Ubuntu atual, /bin é um atalho para /usr/bin.

    /boot

    Arquivos usados para ligar o computador, incluindo o próprio kernel.

    /dev

    Representa dispositivos (discos, USB, terminais) como se fossem arquivos.

    /etc

    Armazena configurações do sistema e dos programas.

    /home

    Local onde ficam as pastas pessoais dos usuários, como /home/aluno.

    /root

    Pasta pessoal do administrador (root). Usuários comuns não têm acesso.

    /tmp

    Arquivos temporários. Costuma ser esvaziado quando o sistema reinicia.

    /usr

    Programas, bibliotecas e recursos instalados para os usuários.

    /var

    Arquivos que mudam com frequência, como logs (/var/log) e filas.

    Caminhos absolutos e relativos

    Absoluto

    /home/aluno/Documentos

    Começa na raiz (/) e funciona de qualquer lugar.

    Relativo

    Documentos ou ../Documentos

    É definido a partir do diretório atual.
    • . diretório atual
    • .. diretório “pai” (um nível acima)
    • ~ sua pasta pessoal (/home/aluno)

    Maiúsculas e minúsculas fazem diferença

    No Linux, Arquivo.txt e arquivo.txt são nomes diferentes. Por isso, atenção à digitação dos nomes e comandos. Arquivos que começam com ponto, como .bashrc, ficam ocultos e só aparecem com ls -a.

    4. Primeiros passos

    Comandos básicos do terminal

    Comandos básicos, finalidade e exemplo de uso
    Comando Finalidade Exemplo Copiar
    pwd Mostra o diretório atual. pwd
    ls Lista arquivos e pastas (-l detalha, -a mostra ocultos). ls -l
    cd Muda de diretório. cd /home/aluno
    mkdir Cria uma nova pasta. mkdir estudos
    touch Cria um arquivo vazio. touch resumo.txt
    echo Mostra um texto; com > grava o texto em um arquivo. echo "Linux" > resumo.txt
    cat Exibe o conteúdo de um arquivo. cat resumo.txt
    cp Copia arquivos (-r para pastas). cp resumo.txt resumo-copia.txt
    mv Move ou renomeia arquivos. mv resumo.txt novo.txt
    rm Apaga arquivos (-r apaga pastas com conteúdo). Não há lixeira! rm novo.txt
    rmdir Apaga uma pasta vazia. rmdir estudos
    man Abre o manual de um comando. man ls

    Entendendo cada parte do comando

    Um comando costuma ter três partes: comando, opções e argumentos. Em ls -l /etc, ls é o comando, -l é a opção (mostrar detalhes) e /etc é o argumento (onde listar).

    Já em cp resumo.txt resumo-copia.txt, o sistema copia o arquivo de origem (primeiro argumento) para o destino (segundo argumento).

    Atalhos e ajuda

    • Tab completa nomes de comandos, pastas e arquivos.
    • ↑ ↓ navegam pelos comandos já digitados.
    • man comando abre o manual completo.
    • comando --help mostra um resumo rápido de uso.
    • clear limpa a tela do terminal.

    5. Usuários e permissões

    Quem pode fazer o quê?

    Usuário comum

    Tem acesso à própria pasta pessoal (~) e a /tmp. Pode ler boa parte do sistema, mas não alterar arquivos de outros usuários nem configurações.

    Administrador (root)

    O usuário root pode tudo: alterar configurações, instalar programas e apagar qualquer arquivo. Por isso, não se trabalha logado como root no dia a dia.

    sudo: agir como administrador só quando precisar

    Colocar sudo antes de um comando o executa com poderes de root, por exemplo sudo apt update para atualizar a lista de programas. O sistema pede a sua senha e registra o uso. Use com cuidado: um comando errado com sudo pode danificar o sistema.

    r w x
    r = leitura
    Arquivo: ver o conteúdo. Pasta: listar o que tem dentro.
    w = escrita
    Arquivo: alterar. Pasta: criar, renomear e apagar itens.
    x = execução
    Arquivo: rodar como programa. Pasta: entrar nela (cd).

    Lendo a saída de ls -l

    Cada linha do ls -l mostra as permissões em três grupos de três letras:

    -rwxr-xr-- 1 aluno aluno 52 out 23 10:00 script.sh
    • - Tipo: - arquivo, d diretório.
    • rwx Dono: pode ler, escrever e executar.
    • r-x Grupo: pode ler e executar.
    • r-- Outros: só podem ler.
    • aluno aluno Usuário dono e grupo dono.

    O traço (-) significa “permissão ausente”.

    Se um arquivo tiver permissão rw-r--r--, isso significa:

    • rw-: o dono pode ler e escrever.
    • r--: o grupo pode apenas ler.
    • r--: outros também podem apenas ler.

    Permissões em números: o comando chmod

    O chmod muda as permissões. A forma numérica soma valores para cada grupo: r = 4, w = 2, x = 1. Por exemplo, rwx = 4 + 2 + 1 = 7 e r-x = 4 + 0 + 1 = 5.

    chmod 644 arquivorw-r--r--: padrão para documentos.
    chmod 755 script.shrwxr-xr-x: programas e scripts.
    chmod 600 senha.txtrw-------: só o dono acessa.
    chmod +x script.shForma simbólica: adiciona execução.

        Glossário

        Kernel
        Núcleo do sistema operacional; controla hardware, memória e processos.
        Shell
        Programa que interpreta os comandos digitados. O mais comum é o bash.
        Terminal
        Janela onde você conversa com o shell digitando comandos.
        Prompt
        Texto antes do cursor, como aluno@ubuntu:~$: usuário, máquina e pasta atual.
        Distribuição
        Pacote completo de Linux: kernel + programas + instalador. Ex.: Ubuntu.
        Diretório
        O mesmo que pasta.
        Raiz (/)
        Diretório inicial de onde partem todos os outros.
        Caminho absoluto
        Endereço completo a partir da raiz, como /home/aluno.
        Caminho relativo
        Endereço a partir da pasta atual, como ../Documentos.
        root
        Usuário administrador, com acesso total ao sistema.
        sudo
        Executa um comando com privilégios de administrador.
        Permissão
        Regra que define quem pode ler (r), escrever (w) ou executar (x).
        Software livre
        Programa que pode ser usado, estudado, modificado e distribuído por qualquer pessoa.
