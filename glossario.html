Glossário

Kernel
Núcleo do sistema operacional; controla hardware, memória e processos.
Shell
Programa que interpreta os comandos digitados. O mais comum é o bash.
Terminal
Janela onde você conversa com o shell digitando comandos.
Prompt
Texto antes do cursor, como aluno@ubuntu:~$: usuário, máquina e pasta atual.
Distribuição
Pacote completo de Linux: kernel + programas + instalador. Ex.: Ubuntu.
Diretório
O mesmo que pasta.
Raiz (/)
Diretório inicial de onde partem todos os outros.
Caminho absoluto
Endereço completo a partir da raiz, como /home/aluno.
Caminho relativo
Endereço a partir da pasta atual, como ../Documentos.
root
Usuário administrador, com acesso total ao sistema.
sudo
Executa um comando com privilégios de administrador.
Permissão
Regra que define quem pode ler (r), escrever (w) ou executar (x).
Software livre
Programa que pode ser usado, estudado, modificado e distribuído por qualquer pessoa.
