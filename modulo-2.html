2. Conhecendo o Linux

O que é Linux?

Um pouco de história

Em 1991, o estudante finlandês Linus Torvalds começou a escrever, como um projeto pessoal, um kernel (núcleo) de sistema operacional. Ele publicou o código na internet e pessoas do mundo todo passaram a contribuir.

Desde 1983, o Projeto GNU, iniciado por Richard Stallman, desenvolvia ferramentas livres (compilador, shell, utilitários). O kernel Linux somado às ferramentas GNU formou um sistema completo; por isso muita gente diz GNU/Linux.

Software livre e código aberto

O Linux é distribuído sob a licença GPL. Isso garante quatro liberdades a qualquer pessoa:

  • Usar o programa para qualquer finalidade.
  • Estudar como ele funciona, lendo o código-fonte.
  • Modificar e adaptar às suas necessidades.
  • Distribuir cópias, originais ou modificadas.

Estrutura do Linux

Kernel

É o núcleo do sistema. Ele gerencia memória, processos, arquivos e dispositivos.

Distribuição

É a combinação do kernel com ferramentas, programas e pacotes do sistema.

Interface gráfica

É a camada visual para interagir com o sistema, como janelas e ícones.

Shell

É o interpretador de comandos (como o bash), onde você digita ordens para o sistema.

Distribuições populares

Ubuntu

Focado em facilidade de uso e com ampla adoção em desktops e servidores.

Debian

Conhecida pela estabilidade e confiabilidade; é a base do Ubuntu e de muitas outras.

Fedora

Traz tecnologias novas rapidamente e é usada em ambientes de inovação e desenvolvimento.

Linux Mint

Baseada no Ubuntu, tem visual familiar para quem está vindo do Windows.

Arch Linux

Minimalista: você monta o sistema peça por peça. Ótima para aprender a fundo.

Onde o Linux aparece?

  • Computadores pessoais e notebooks.
  • Servidores web e bancos de dados: a maior parte da internet roda em Linux.
  • Celulares Android, que usam o kernel Linux.
  • Dispositivos embarcados, roteadores e smart TVs.
  • Ambientes de desenvolvimento, nuvem e supercomputadores.
